# BillWise.com Setup Guide

## Prerequisites

- Node.js (v18 or higher)
- PostgreSQL (v14 or higher)
- npm or yarn

## Step 1: Install Dependencies

From the root directory, run:

```bash
npm run install:all
```

This will install dependencies for:
- Root package (concurrently for running both servers)
- Frontend (React, Vite, Tailwind, etc.)
- Backend (Express, Prisma, etc.)

## Step 2: Database Setup

1. **Create PostgreSQL Database**

```sql
CREATE DATABASE billwise;
```

2. **Configure Environment Variables**

Copy the example environment file:

```bash
cd backend
cp .env.example .env
```

Edit `backend/.env` and update:

```env
DATABASE_URL="postgresql://username:password@localhost:5432/billwise?schema=public"
JWT_SECRET="your-super-secret-jwt-key-change-in-production-min-32-chars"
PORT=3000
NODE_ENV=development
```

Replace `username` and `password` with your PostgreSQL credentials.

3. **Run Database Migrations**

```bash
cd backend
npx prisma migrate dev --name init
npx prisma generate
```

This will:
- Create the database schema (User, Bill, Expense tables)
- Generate Prisma Client

## Step 3: Start Development Servers

From the root directory:

```bash
npm run dev
```

This starts:
- **Frontend**: http://localhost:5173
- **Backend API**: http://localhost:3000

## Step 4: Test the Application

1. Open http://localhost:5173 in your browser
2. Click "Get Started" or navigate to `/register`
3. Create an account
4. Upload a dummy bill from the dashboard
5. Explore all features:
   - Bill analysis
   - Expense tracking
   - AI Chat
   - Bill Literacy hub

## Troubleshooting

### Database Connection Issues
- Ensure PostgreSQL is running
- Check DATABASE_URL in `backend/.env`
- Verify database exists: `psql -l | grep billwise`

### Port Already in Use
- Change PORT in `backend/.env`
- Update proxy in `frontend/vite.config.js`

### Prisma Issues
- Run `npx prisma generate` in backend folder
- Check Prisma schema syntax

### Frontend Not Loading
- Clear browser cache
- Check browser console for errors
- Ensure backend is running on port 3000

## Production Build

### Frontend
```bash
cd frontend
npm run build
```

### Backend
```bash
cd backend
npm start
```

## Environment Variables for Production

Update these in production:
- `JWT_SECRET`: Use a strong, random secret (32+ characters)
- `DATABASE_URL`: Production database connection string
- `NODE_ENV`: Set to `production`
